# 模拟器 → 板卡 UI 移植规范

> 目标：在 PC 模拟器里把界面调好，拷到 AT32F403A 工程后**不改一行代码**就能一模一样地显示。
>
> 前提：两边跑的是**同一份 SGL**（已核对，只有 `sgl_snprintf.c` / `sgl_draw_arc.c` 因 ARMCC v5 兼容被改过，API 完全一致），所以不存在"版本不兼容"问题。真正的坑只有下面五类。

## 2. 代码分层：[A] 段 / [B] 段

两个页面文件都按同一格式切开，**只有 [A] 段需要保持一致**：

```
[A] 平台无关  =  #define 布局宏 + 控件指针 + 状态变量 + 动态文本缓冲
                  + ui_label/ui_label_dyn/ui_button 三个小工具
                  + ui_refresh_*() 局部刷新
                  + 事件回调 (ui_btn_xxx_cb)
                  + ui_page_build(sgl_obj_t *root)
                  + ui_page_task(uint32_t now_ms)

[B] 平台相关  =  模拟器: main() + SDL 初始化 + while 循环 + 鼠标
                 板卡  : UiDemo_Init() + UiDemo_Task() + BM_GetTick()
```

两条硬性约定，保证两边能共用同一段源码：

1. **页面代码不许出现平台 API**。所有时间判断用 `now_ms` 差值，不用 `delay`、不用定时器：
   ```c
   static void ui_page_task(uint32_t now_ms)
   {
       static uint32_t t_prog;
       if ((uint32_t)(now_ms - t_prog) >= 200u) { t_prog = now_ms; /* ... */ }
   }
   ```
2. **板卡专属的一行代码用宏包住**，模拟器不定义该宏，那段就自动消失：
   ```c
   #ifdef UI_PORT_BOARD
       at32_led_toggle(LED2);
   #endif
   ```

## 3. 五类必踩的坑

### 坑 1：控件摆出画布（最常见）

板卡 SGL 行缓冲按当前方向的宽度分配（横屏 **320**、竖屏 240），`st7789_blit()` 还会把超出的部分裁掉。横屏下 `x > 319` 或 `y > 239` 的控件在板上**直接消失**，而模拟器（如果窗口还是 240×320）里看着是好的。

- 现象：模拟器正常，板上只显示左上角一块 / 右边整列不见了
- 修法：模拟器窗口必须与板卡同方向同尺寸（当前都是 320×240），越界当场就能看见
- 检查：`python tools/ui_port_check.py`

### 坑 2：`set_text_fmt` 打到没绑缓冲的 label

`sgl_label_set_text()` **只存指针、不设 `text_capacity`**：

```c
/* sgl_label.c —— set_text 里根本没有碰 text_capacity */
label->text = (char*)text;
```

于是对这样一个 label 调 `sgl_label_set_text_fmt()`，内部 `sgl_vsnprintf(buf, 0, ...)` 写进去是**空串**；如果 label 指针还是 NULL（比如从模拟器搬代码时忘了把局部变量提升成 static），`sgl_container_of(NULL, ...)` 会读低地址拿野指针再往里写，直接 HardFault。

- 现象：文字不变 / 文字消失 / 初始化阶段就死机（整屏不刷新）
- 修法：会变的标签一律走 `ui_label_dyn()`：

```c
static char s_buf_pct[16];                      /* 生命周期 = 整个程序 */
s_lbl_pct = ui_label_dyn(root, ..., s_buf_pct, sizeof(s_buf_pct));
sgl_label_set_text_fmt(s_lbl_pct, "PROG %u %%", v);
```

### 坑 3：控件指针用完就丢

模拟器的 `main()` 里控件指针是局部变量，函数返回就没了。搬到板卡后如果 `UiDemo_Task()` 还要更新它，必须提升成文件级 `static sgl_obj_t *s_xxx;`。**漏一个就是 NULL 访问**。

- 判断方法：`ui_page_task()` / 回调里用到的每一个指针，都必须在文件顶部有 `static sgl_obj_t *` 声明。

### 坑 4：用了板卡没编译的控件

Keil 工程刻意跳过了 9 个依赖文件系统/解码器的控件目录：

```
filebrowser  filedialog  gif  gifdec  img_ext
label_ext    avi         unzip_image     3dvortex
```

其余 61 个控件都在。用了这几个 → 链接报 `undefined symbol`。

### 坑 5：配置漂移

| 配置项 | 模拟器 | 板卡 | 说明 |
|---|---|---|---|
| `CONFIG_SGL_HEAP_MEMORY_SIZE` | 16384 | 16384 | **必须相等**。模拟器给 100KB 时页面超预算只在板上失败 |
| `CONFIG_SGL_EVENT_QUEUE_SIZE` | 8 | 8 | 一次投递超过 8 个事件会丢 |
| `CONFIG_SGL_BOOT_LOGO` | 0 | 0 | 开着的话模拟器多一段开机动画，板上没有 |
| `CONFIG_SGL_MONITOR_TRACE` | 0 | 0 | 开着会在右上角画 FPS/内存叠层，板上不存在这块脏区 |
| `CONFIG_SGL_PIXMAP_BILINEAR_INTERP` | 0 | 0 | 图片缩放观感不同 |
| 字体 | 5 个全开 | 5 个全开 | `consolas14/23/24/32` + `song23`（CJK） |
| `CONFIG_SGL_COLOR16_SWAP` | **0** | **1** | 唯一允许不同：SDL 直接上传 RGB565，ST7789 要高字节先出 |
| `CONFIG_SGL_DEBUG` / `LOG_*` | 1 | 0 | 允许不同：只影响控制台 |

`kai33` 两边都没有字体源文件，必须保持 0。上游 `sgl_cfgfix.h` 里**没有** `CONFIG_SGL_FONT_SGL_ICON_PLAYER32` 这个宏（写了也不生效），图标字体只有 `sgl_icon_fontawesome14`。

> CMake 里原来的配置同步是 `POST_BUILD`，改完配置要等**下一次**构建才生效——第一次必然用旧配置编。已改成独立 target + `add_dependencies(sgl sgl_config_sync)`，构建前同步。

## 4. 标准搬运流程

```bash
# 1. 在模拟器里设计（VS Code 打开 sgl-port-windows-vscode，运行 sgl_simulator）
#    只用这 5 个字体、避开那 9 个控件、画布当成 320x240 用

# 2. 把 demo/main.c 里 [A] 段整段复制，覆盖 app/Src/ui_demo.c 的 [A] 段
#    （两个文件里都有 "[A] 平台无关部分" 和 "[A] 段结束" 两条横幅，夹在中间的就是）

# 3. 校验
cd C:\Users\zed\Desktop\AT32F403A_Project
python tools/ui_port_check.py

# 4. 编译
"C:\Keil_v5\UV4\UV4.exe" -b mdk_v5\AT32F403A_Project.uvprojx -j0 -o mdk_v5\build.log
```

校验脚本会做 6 项检查（全部带行号）：

| # | 检查 | 触发条件 |
|---|---|---|
| 1 | 画布尺寸声明 | 两边 `UI_W × UI_H` 不是板卡当前方向的 320×240 |
| 2 | **[A] 段逐行 diff** | 两边代码漂移（指出具体行） |
| 3 | 控件可用性 | 用了那 9 个被跳过的控件 |
| 4 | 字体可用性 | 不在 5 个白名单内 |
| 5 | 坐标越界 | 解析 `#define` 后算出真实 x/y/w/h 超出画布 |
| 6 | 动态文本缓冲 / 平台残留 | fmt 打到没绑缓冲的 label；板卡文件里有 `SDL_*` / `main()` / `while(1)` |

退出码 0 = 全过，1 = 有 ERROR。

## 5. 要动结构时怎么做

### 加一个新字体
两边同时做，否则必挂：
1. 板卡：`fonts/sgl_ascii_xxx.c` 加入 Keil 工程的 `sgl_font` 分组
2. 两侧 `sgl_config.h` 都打开 `CONFIG_SGL_FONT_XXX 1`
3. `tools/ui_port_check.py` 的 `ALLOWED_FONTS` 加上名字
4. 字体是 `const`，只吃 flash 不吃 RAM；没用到的符号会被 linker 丢掉，不占空间

### 加一个新控件
1. 两侧 SGL 源码同一个版本，控件天然都在（除了那 9 个）
2. 板卡：把 `third_party/sgl/widgets/<新控件>/*.c` 加进 Keil 的 `sgl_widget` 分组
3. 如果依赖文件系统/图片解码，就加到 `BANNED_WIDGETS` 里并接受"板上不可用"

### 切横屏 / 切竖屏
现在**只需要一个宏**：`BSP/UI_Driver/sgl_port_at32.h` 的 `SGL_PORT_LANDSCAPE`（0=竖屏 240×320，1=横屏 320×240）。它会同时决定 `st7789_set_rotation()` 的方向和行缓冲宽度。

但还有三处**不会自动变**，必须跟着改：

| # | 位置 | 说明 |
|---|---|---|
| 1 | `app/Src/ui_demo.c` 的 `UI_W/UI_H` 与所有坐标 | 布局要重排（横屏用左右分栏） |
| 2 | `demo/main.c` 的 `UI_W/UI_H` 与所有坐标 | 与板卡保持逐字相同 |
| 3 | `demo/sgl_port_sdl2.c` 的 `CONFIG_SGL_PANEL_WIDTH/HEIGHT` | 模拟器窗口尺寸 |

`CONFIG_SGL_FBDEV_ROTATION` 永远保持 **0**：旋转由 ST7789 的 MADCTL 完成，改成 90 会让 SGL 再软件旋转一次（多分配 25.6KB + 每帧逐像素搬运），结果转两次。

详细原理与布局写法见 `Docs/UI/SGL_横屏与控件使用手册.md` §1。
